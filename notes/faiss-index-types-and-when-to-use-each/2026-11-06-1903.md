# FAISS Index Types & Selection

**Flat indexes** (`IndexFlatL2`, `IndexFlatIP`) perform exact brute-force search. Use `L2` for Euclidean distance; `IP` for cosine similarity (normalize vectors first). Guarantees 100% recall but scales poorly beyond ~1M vectors. Ideal for baselines, small datasets, or re-ranking candidates from an ANN index.

**IVF (Inverted File)** indexes (`IndexIVFFlat`, `IndexIVFPQ`) partition space via k-means into `nlist` Voronoi cells. At query time, probe `nprobe` nearest cells. Trade-off: higher `nprobe` = better recall, slower speed. `IVFFlat` stores full vectors (exact within cell); `IVFPQ` adds Product Quantization (compression) for massive datasets (10M–1B+ vectors) with modest RAM. **Always call `index.train()` before `add()`.**

**HNSW** (`IndexHNSWFlat`) builds a navigable proximity graph. Best query speed/recall trade-off for medium datasets (1M–10M) fitting in RAM. No training required. Parameters: `M` (graph connectivity, 16–64) and `efConstruction` (index build quality). Set `efSearch` at query time to tune speed/recall.

```python
import faiss
import numpy as np

d, nb, nq = 128, 10000, 100
xb = np.random.random((nb, d)).astype('float32')
xq = np.random.random((nq, d)).astype('float32')

# IVF + PQ: 100 centroids, 8-byte codes (16 subvecs * 4 bits)
nlist, m = 100, 16
quantizer = faiss.IndexFlatL2(d)
index = faiss.IndexIVFPQ(quantizer, d, nlist, m, 8)
index.train(xb)          # Mandatory for IVF/PQ
index.add(xb)
index.nprobe = 10        # Search 10 cells
D, I = index.search(xq, 5)
print(I[:3])
```
